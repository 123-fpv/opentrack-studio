# 验证记录

版本：0.1.3。更新：2026-10-27。Windows x64，MSVC 2022，Qt 6.8.3，全新 Release 构建。

## 已完成

- 10 项 CTest 全部通过：工程、颜色、几何、本地识别、原生赛道、AI 请求解析、图片拖入、2D 画布、3D 场景及应用流程。
- 标准门每格中心距 3 m、杆长 3.2 m、截面 0.1 × 0.1 m、净开口 2.9 m；转向柱 0.1 × 0.1 × 3.2 m。双联、三联、叠门、立方和双层立方共用完整杆件几何，验证唯一梁数、整体边界、贴地高度及可选通过列、层。旧工程保留原尺寸约定。
- 黑白界面、图标与选中光圈，内置操作说明和快速上手文档；组件可独立设置颜色，选中后保留自身颜色。
- 组件 RGB 颜色的保存、加载、非法值拒绝及失败时不覆盖原文件；新建方块组件输出 13 种原生颜色，其他 RGB 匹配最近颜色。
- 工程保存、嵌入底图、非法输入拒绝、失败时不修改当前工程。
- 本地深色轮廓与洋红路线识别：一张包含 16 组障碍物的设计图，在原尺寸、75% 和 150% 缩放下均恢复 16 组及组合类型，未将图例或起飞台当作障碍；这些检查全部在本地完成。简单蓝色检测仍验证示例位置、边框排除、缩放映射、空图和宽门歧义。单张图的成功不代表任意设计图均适用，测试原图未随源码或发布包公开。
- 原生赛道文件：独立 AES 已知答案、坐标及旋转、扩展数据保留、损坏文件拒绝；五类组合的完整梁数、窗口、颜色、重复往返及复制删除归属，相邻单门不误并为组合。
- 2D 和 3D 两步移动：首次点击只选中，继续移动不会改变门位；再次按住拖动才开始移动，支持撤销。
- 3D 场景的软件预览交互：选取、拖动、吸附、环绕、平移、缩放、放置及组合显示；坐标指示器验证编辑器 X/Y 地面、Z 向上与原内部坐标的映射。2D 组合图标和组件颜色有独立回归检查。
- AI 请求与解析：多图编码、尺寸限制、模型图片能力、严格数值校验、取消以及密钥不进入请求正文或工程。
- 应用流程：向左侧小框、2D 画布和 3D 场景发送实际 `QDropEvent`，经异步读取生成，验证一次撤销恢复导入前整个工程。导入流程已实现后一次请求优先及工程修改后丢弃过期结果的保护；多图拖入只打开 AI 窗口，不自动生成或发送图片。

CTest 的自动界面测试使用 Qt `offscreen` 与软件透视回退；另在原生 Windows 窗口运行应用流程，通过小框、俯视图和真实 3D 场景三处拖入及整次撤销检查，并检查了原生 3D 画面。新增 Windows 字体彩色边缘碎片回归，避免标题文字被误认成门。大留白底图下的组件聚焦也有回归检查。这些验证不代表跨显卡驱动兼容性或帧率基准。

## DeepSeek 官方接口实测

官方模型列表返回 `deepseek-flash` / DeepSeek-V4.1-Flash，输入类型为 `text`、`image`。

0.1.3 默认勾选“快速生成”，请求使用 `thinking.type = disabled`；取消勾选时启用思考模式。该参数依据 [DeepSeek 官方 Thinking Mode 文档](https://api-docs.deepseek.com/guides/thinking_mode/)。

一次快速模式有效响应约用 4.455 秒，但只生成 15 组对象，并漏掉部分组合结构；此前也出现过无效 JSON 响应。无效数据不能作为有效草稿应用。此记录验证接口流程及失败边界，不证明识别准确率或固定响应时间。

选图或打开 AI 窗口不会发送图片，只有明确点击“生成草稿”才会发送缩放后的选定图片。密钥可由本机 Windows 凭据管理器保存，源码、工程及发布包均不包含用户密钥。
