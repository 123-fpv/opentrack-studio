# 验证记录

更新：2026-10-27。Windows x64，MSVC 2022，Qt 6.8.3，Release 构建。

## 已完成

- 0.1.2 尺寸与颜色：标准门中心距 3 m、杆长 3.2 m、方截面 0.1 m、净开口 2.9 m；转向柱 0.1 × 0.1 × 3.2 m。共享杆件几何校验实际边界及贴地高度，旧工程保留原尺寸约定。
- 黑白界面、图标与选中光圈，内置操作说明和快速上手文档；组件可独立设置颜色，选中后保留自身颜色。
- 组件 RGB 颜色的保存、加载、非法值拒绝及失败时不覆盖原文件；新建方块组件输出 13 种原生颜色，其他 RGB 匹配最近颜色。
- 工程保存、嵌入底图、非法输入拒绝、失败时不修改当前工程。
- 本地蓝色门架识别：示例位置、边框排除、缩放映射、空图和宽门歧义。
- 原生赛道文件：独立 AES 已知答案、坐标及旋转、原生扩展数据保留、损坏文件拒绝；四杆组合门、转向柱及不可见检查点的几何、颜色、重复导入导出与复制删除归属。
- 2D 和 3D 两步移动：首次点击只选中，继续移动不会改变门位；再次按住拖动才开始移动，支持撤销。
- 原生 OpenGL 场景和软件预览：选取、拖动、吸附、环绕、平移、缩放、放置及退出放置。
- AI 请求与解析：多图编码、尺寸限制、模型图片能力、严格数值校验、取消以及密钥不进入请求正文或工程。
- 应用流程：示例图识别出 13 个门架，工程及 `.trk` 往返，颜色属性实际控件的撤销、重做和保存。

## DeepSeek 官方接口实测

官方模型列表返回 `deepseek-flash` / DeepSeek-V4.1-Flash，输入类型为 `text`、`image`。

以项目原创的示例俯视图作为输入，实际请求约用 40.5 秒，生成 13 个门架，并成功保存 `.otproj`、导出 `.trk`。这是一张示例图的流程验证，不代表其他图片的识别准确率或固定响应速度。密钥只在本机 Windows 凭据管理器中保存，源码及发布包不包含密钥。
