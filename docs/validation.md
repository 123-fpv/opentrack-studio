# 验证记录

日期：2026-10-26。Windows x64，MSVC 2022，Qt 6.8.3，Release 构建。

## 已完成

- 工程保存、嵌入底图、非法输入拒绝、失败时不修改当前工程。
- 本地蓝色门架识别：示例位置、边框排除、缩放映射、空图和宽门歧义。
- 原生赛道文件：独立 AES 已知答案、坐标及旋转、原生扩展数据保留、损坏文件拒绝；转向柱拉伸方块与旁侧检查点的几何一致性及反复导入导出。
- 2D 和 3D 两步移动：首次点击只选中，继续移动不会改变门位；再次按住拖动才开始移动，支持撤销。
- 原生 OpenGL 场景和软件预览：选取、拖动、吸附、环绕、平移、缩放、放置及退出放置。
- AI 请求与解析：多图编码、尺寸限制、模型图片能力、严格数值校验、取消以及密钥不进入请求正文或工程。
- 应用流程：示例图识别出 13 个门架，工程及 `.trk` 往返，撤销及重做。

## DeepSeek 官方接口实测

官方模型列表返回 `deepseek-flash` / DeepSeek-V4.1-Flash，输入类型为 `text`、`image`。

以项目原创的示例俯视图作为输入，实际请求约用 40.5 秒，生成 13 个门架，并成功保存 `.otproj`、导出 `.trk`。这是一张示例图的流程验证，不代表其他图片的识别准确率或固定响应速度。密钥只在本机 Windows 凭据管理器中保存，源码及发布包不包含密钥。
