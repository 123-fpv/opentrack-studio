# 快速上手

第一次打开会显示示例赛道。可以先在示例上练习选择、移动和保存，再导入自己的图片。

## 先学会移动组件

1. **单击门架或转向柱，松开鼠标**，看到地面选中光圈。
2. 再按住这个组件，或按住它脚下的光圈拖动，即可调整平面位置。细柱较难点中时，可以点击它上方的编号，再拖光圈。
3. 在左侧属性中修改尺寸、中心高度和朝向；转向柱还有“绕柱通过侧”。

第一次按住尚未选中的组件，只完成选择；松开后再拖动。需要放新组件时，先点击右侧组件卡片，再点击场景放置，按 `Esc` 返回选择工具。

| 想做什么 | 操作 |
| --- | --- |
| 旋转 3D 视角 | 按住右键拖动，或拖动场景空白处 |
| 平移视角 | 中键拖动，或按住空格加左键拖动 |
| 缩放 | 滚轮 |
| 找回整条赛道 | 按 `F`，或点击“适应视角” |
| 平面定位 | 点击场景上方“俯视图” |
| 旋转选中组件 | `Q` / `E`，每次 15° |
| 复制 / 删除 | `Ctrl+D` / `Delete` |
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Shift+Z` |

## 从图片生成赛道

**蓝色门架的平面设计图：** 点击左侧“导入平面图并识别”，选择图片后自动识别。图片在本机处理。先裁掉视频界面、字幕和组件库，会更容易识别；漏掉的组件可手动补上。

**实拍或航拍照片：** 点击“照片生成赛道（AI）”，添加同一场地的 1–8 张照片，填写已知门宽和飞行顺序，设置自己的 DeepSeek API 密钥。点击“生成草稿”后才会发送照片；检查 3D 预览后，点击“使用这份草稿”应用到工程。

已知门宽指门框的开口宽度。转向柱的“宽度”指柱体厚度，需要单独校对。

## 生成后检查什么

- 位置、比例、高度和朝向：图片无法提供的尺寸会被估算。中心高度是组件中心离地的高度；贴地的 2.4 米高门，中心高度通常为 1.2 米；3 米高柱通常为 1.5 米。
- 转向柱：选中柱子，在左侧选择“右侧绕过”或“左侧绕过”。左右以柱子的朝向为准；`0°` 朝 `+Z`，`90°` 朝 `+X`。
- 通过顺序：点击底部对应组件，用“前移”“后移”调整；交叉、重复穿门和绕柱顺序要重点检查。“航线预览”用于检查布局。

## 保存和导入黑羊模拟器

1. 点击“保存工程”或按 `Ctrl+S`，得到 **`.otproj` 工程**，以后打开它继续编辑。
2. 点击“导出赛道 .trk”，得到 **`.trk` 赛道文件**。
3. 将 `.trk` 放到 Windows“文档”目录，在 VelociDrone 的 **Track Editor → Import Track** 中导入。
4. 在模拟器中检查尺寸、通过方向、门序和地面高度，再试飞。当前版本仍需完成安装版模拟器的实际导入及飞行验收。

更多设置见 [完整使用说明](usage.md)。
