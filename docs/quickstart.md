# 快速上手

OpenTrack Studio 0.1.3 第一次打开会显示示例赛道。可以先练习选择、移动和保存，再导入自己的图片。无需应用账号登录。

## 先学会移动组件

1. **单击门架或转向柱，松开鼠标**，看到地面选中光圈。
2. 再按住这个组件，或按住它脚下的光圈拖动，即可调整平面位置。细柱较难点中时，可以点击它上方的编号，再拖光圈。
3. 在左侧属性中修改尺寸、Z 中心高度、朝向和颜色；**X / Y 是地面位置，Z 向上**。转向柱可选“绕柱通过侧”，组合门可选“通过格”的列、层。可选 13 种模拟器方块颜色，也可点“调色”选 RGB，导出时匹配最近的原生颜色。

第一次按住尚未选中的组件，只完成选择；松开后再拖动。需要放新组件时，先点击右侧组件卡片，再点击场景放置，按 `Esc` 返回选择工具。

| 想做什么 | 操作 |
| --- | --- |
| 旋转 3D 视角 | 按住右键拖动，或拖动场景空白处 |
| 平移视角 | 中键拖动，或按住空格加左键拖动 |
| 缩放 | 滚轮 |
| 找回整条赛道 | 按 `F`，或点击“适应视角” |
| 平面定位 | 点击场景上方“俯视图” |
| 旋转选中组件 | `Q` / `E`，每次 15° |
| 复制 / 删除 | `Ctrl+D` / `Delete` |
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Shift+Z` |

## 从图片生成赛道

**单张平面设计图：** 将 PNG / JPG / BMP 拖到左侧“拖入赛道图片”小框、3D 场景或俯视图，也可点击小框选图。程序自动在本机生成，不上传图片。深蓝轮廓配洋红路线的图支持识别组合门和路线顺序；简单蓝色图使用基础检测。先裁掉视频界面、字幕和组件库，生成后仍需检查漏检、门型和门序。

导入完成后，按一次 `Ctrl+Z` 可恢复导入前的底图和组件。连续拖图以最后一次为准；识别期间若修改工程，旧结果会被丢弃。

**实拍或航拍照片：** 一次拖入多张照片，或点击“照片生成赛道（AI）”，添加同一场地的 1–8 张照片，填写已知门宽和飞行顺序，设置自己的 DeepSeek API 密钥。打开窗口、选图都不会上传；点击“生成草稿”后才发送。默认勾选“快速生成”，复杂组合可取消后重试，耗时与准确率均无保证。检查 3D 预览后，点击“使用这份草稿”应用到工程。

已知门宽指左右立柱的中心距。新建标准门的横、竖中心距均为 **3 m**，四根杆各长 **3.2 m**、截面 **0.1 × 0.1 m**，净开口 **2.9 × 2.9 m**。杆件包含交叉重叠处和端部伸出部分。转向柱默认长 **3.2 m**，截面 **0.1 × 0.1 m**。

右侧展开“组合门”可放置双连、三连、日字、单层及双层重力门。组合门尺寸按**每格** 3 × 3 m 中心距计算；选中后在左侧选择穿过第几列、第几层，默认最左、最低格。日字门和双层重力门贴地时，整个组件的 Z 中心高度为 3.1 m，单门及其余组合为 1.6 m。

## 生成后检查什么

- 位置、比例、高度和朝向：图片无法提供的尺寸会被估算。中心高度是组件中心离地的高度；上述标准门和转向柱贴地时，中心高度均为 1.6 m。选中标准门会显示中心距、杆长、截面和净开口。旧工程及导入的原生门保留各自的尺寸约定。
- 转向柱：选中柱子，在左侧选择“右侧绕过”或“左侧绕过”。左右以柱子的朝向为准；编辑器中 `0°` 朝地面平面的 `+Y`，`90°` 朝 `+X`。右下角坐标指示器的 Z 轴表示向上。
- 通过顺序：点击底部对应组件，用“前移”“后移”调整；交叉、重复穿门和绕柱顺序要重点检查。“航线预览”用于检查布局。
- 组合门：检查每格结构和所选“通过格”；一组目前只有一个顺序检查点，不能自动表达反复穿越不同格的完整流程。
- AI 草稿：可能少识别门架、漏掉组合或返回无效结果；应用前逐项检查，不把一次成功当作精度保证。

内部及模拟器的坐标转换由程序处理，旧工程的位置和朝向保持兼容。

## 保存和导入黑羊模拟器

1. 点击“保存工程”或按 `Ctrl+S`，得到 **`.otproj` 工程**，以后打开它继续编辑。
2. 点击“导出赛道 .trk”，得到 **`.trk` 赛道文件**。
3. 将 `.trk` 放到 Windows“文档”目录，在 VelociDrone 的 **Track Editor → Import Track** 中导入。
4. 在模拟器中检查尺寸、通过方向、门序和地面高度，再试飞。当前版本仍需完成安装版模拟器的实际导入及飞行验收。

更多设置见 [完整使用说明](usage.md)。
